# 義式餐廳點餐系統

使用 HTML、CSS、JavaScript 與 Bootstrap 5 開發的義式餐廳線上點餐網站，模擬使用者瀏覽餐點、客製化商品、管理購物車及結帳的操作流程。

本專案為個人獨立完成的前端作品，主要練習 JavaScript DOM 操作、事件處理、陣列資料處理及 Bootstrap 元件應用。

## 使用技術

- **前端：** HTML5、CSS3、JavaScript（Vanilla JS）
- **UI 框架：** Bootstrap 5、Bootstrap Icons
- **資料儲存：** LocalStorage
- **版本控制：** Git、GitHub

## 主要功能

### 1. 餐點展示與分類
- 以卡片方式展示餐點圖片、名稱與價格。
- 提供主餐、開胃菜、飲品、甜點等分類篩選。

### 2. 購物車管理
- 新增餐點至購物車。
- 調整商品數量。
- 自動計算購物車總金額。
- 使用 LocalStorage 保存購物車資料。

### 3. 餐點客製化
- 使用 Bootstrap Modal 顯示客製化選項。
- 支援餐點加料及其他可選項目。
- 根據選擇調整商品價格。

### 4. 操作提示與模擬結帳
- 使用 Bootstrap Toast 顯示加入購物車的通知。
- 模擬訂單送出流程，顯示結帳成功訊息。
- 本專案為前端模擬系統，未串接後端訂單 API 或金流服務。

## 專案特色

- 使用原生 JavaScript 實作主要互動功能。
- 使用 Bootstrap 建立響應式網頁介面。
- 結合 Modal、Toast 與 LocalStorage，模擬完整的前端點餐操作體驗。
